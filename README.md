# 🎮 Game Store

.NET Core kullanılarak geliştirilmiş, kullanıcıların oyunları görüntüleyebildiği, inceleyebildiği ve yönetebildiği örnek bir oyun mağazası uygulamasıdır.

## 🚀 Proje Hakkında

Bu proje, ASP.NET Core MVC mimarisini öğrenmek ve modern web geliştirme süreçlerini uygulamak amacıyla geliştirilmiştir. Uygulama içerisinde oyunların listelenmesi, detaylarının görüntülenmesi ve temel CRUD (Create, Read, Update, Delete) işlemleri gerçekleştirilebilmektedir.

## ✨ Özellikler

- 🎮 Oyun listeleme
- 🔍 Oyun detaylarını görüntüleme
- ➕ Yeni oyun ekleme
- ✏️ Oyun bilgilerini güncelleme
- ❌ Oyun silme
- 📂 Kategorilere göre oyun yönetimi
- 🗄️ Entity Framework Core ile veritabanı işlemleri
- 📱 Responsive kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

## ⚙️ Kurulum

1. Repoyu bilgisayarınıza klonlayın.

```bash
git clone https://github.com/kullaniciadi/GameStore.git
```

2. Projeyi Visual Studio ile açın.

3. Veritabanı bağlantı ayarlarını `appsettings.json` dosyasından düzenleyin.

4. Migration'ları uygulayın.

```powershell
Update-Database
```

5. Projeyi çalıştırın.
